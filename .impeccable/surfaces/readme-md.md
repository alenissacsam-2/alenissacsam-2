## Direction contract

THESIS: The profile is a passport that is actually signed. Every build is attested with Sigstore; visitors verify it with one command and can be issued a stamp of their own. Refuses the category default: dark terminal banner + stat-card wall + badge rows.

OWN-WORLD: Security printing. Daylight (light mode): cool security paper #E8EEEC, intaglio ink #13213A, teal and lavender guilloché hairlines, serial red #C42F2A. UV lamp (dark mode): blue-black #0B0A1A ground, the same document seen under 365nm light, fluorescent guilloché and fibres in #5CF2C8 / #FF5FA8 / #7FA8FF, hidden UV monogram only visible here. Archivo (expanded caps labels, bold values), Azeret Mono for MRZ and serials. Hairlines, no cards, no radius beyond the document's own corners.

STORY: Visitor sees a passport cover swing open onto a data page: name, field, institution, document number = README hash. They read the visa stamps (projects, each clickable), the perforated activity log, turn the 3D seal, and learn they can verify the page or get stamped themselves.
