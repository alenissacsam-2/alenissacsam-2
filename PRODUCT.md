## Platform

web (GitHub profile README: Markdown + SVG images rendered by github.com)

## Users

Visitors to github.com/alenissacsam-2: recruiters and hiring engineers scanning a candidate, hackathon teammates, and other Web3 / AI developers. (Inferred from the repo and its old copy; not confirmed in an interview, the user waived questions.)

## Product Purpose

Alen Issac Sam's GitHub profile. It should make a visitor remember him in one viewport and send them into his repos. Success, in the user's words: when he sees it, it should be cool in a way nobody has done before, and clean.

## Positioning

His work is decentralized identity and verifiable credentials (Algorand DID + trust score, Ethereum identity dApp, on-chain certificate registry), plus AI agents (Google ADK), neural nets from scratch, and market microstructure tooling. Motto already in use: "Don't trust. Verify." / "Trust should be verifiable, not assumed."

## Operating Context

Rendered by GitHub: images only (SVG via `<img>`/`<picture>`, no scripts, no hover), CSS/SMIL animation allowed, `<picture>` dark/light sources, Markdown, `<details>`, image links. Data refreshed by GitHub Actions on a schedule.

## Capabilities and Constraints

- Generated assets come from Python in `.github/scripts/`, run by Actions with the default `GITHUB_TOKEN`.
- No paid or third-party hosted widgets that can go down.
- Facts on hand: Kerala, India; IIT Hyderabad; chains Ethereum + Algorand; stack Solidity, PyTeal, TypeScript, Python.

## Evidence on Hand

Real repos listed in `.github/scripts/build_cards.py` (FEATURED, DESCRIPTIONS). Live GitHub stats via GraphQL. No testimonials, employers or metrics beyond GitHub data; do not invent them.

## Product Principles

1. Prove, don't claim: anything the profile asserts should be checkable.
2. One idea, executed fully, over a pile of widgets.
3. Clean: restraint in count, ambition in craft.
